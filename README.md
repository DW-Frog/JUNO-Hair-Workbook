# 준오헤어 「시험 공부 게임」 🎮

직원 교육용 **가격·할인 규칙 암기 퀴즈 게임**입니다.
아이폰 12 Pro(390×844) 화면에 맞춰 디자인했고, 실제 모바일 브라우저에서는 풀스크린으로 동작합니다.

---

## 🧩 사용한 기술 / 스킬

| 구분 | 내용 |
|------|------|
| **마크업/스타일** | HTML + 순수 CSS (외부 UI 프레임워크 없음) |
| **인터랙션** | React 18 (UMD) + Babel (브라우저 인-라인 JSX 컴파일) |
| **상태/저장** | React `useState`/`useRef` + `localStorage` (진행상황 자동 저장) |
| **폰트** | `Jua`(귀여운 제목용, Google Fonts) + `Pretendard`(본문/숫자, CDN) |
| **적용 디자인 스킬** | **Hi-fi design**(고완성도 모바일 UI) · **Interactive prototype**(실제 동작하는 앱) |
| **비주얼 콘셉트** | 귀엽고 활기찬 게임풍 — 컬러풀 카드, 이모지, 콤보/컨페티 효과 |

> 빌드 도구 없이 브라우저만으로 실행됩니다. `index.html`을 열면 바로 동작합니다.

## 📁 파일 구조

```
시험 공부 게임/
├── index.html        # 진입점: 폰트·스크립트 로드 + 아이폰 셸 + 화면 스케일링
├── styles.css        # 전체 디자인 시스템(색상 토큰·버튼·카드·애니메이션)
├── questions.js      # 📚 전체 문제 은행(87문제) + 분야 메타데이터  ← 데이터 수정은 여기서
├── util.js           # 🧠 로직: 채점·레벨/경험치·점수·오답관리·저장 (window.QU)
├── screens.jsx       # 홈 / 분석 / 오답노트 / 프로필 화면
├── quiz.jsx          # 퀴즈 엔진(문제 출제·입력·채점·콤보·효과)
├── result.jsx        # 결과 화면(점수·레벨업·분야별 요약)
└── app.jsx           # 루트: 화면 라우팅 + 하단 탭바
```

### 로드 순서 (index.html)
```
React → ReactDOM → Babel
  → questions.js (데이터)
  → util.js (로직)
  → screens.jsx → quiz.jsx → result.jsx → app.jsx (화면)
```
`questions.js`·`util.js`는 일반 JS로 `window`에 전역 등록되고,
`*.jsx`는 Babel이 브라우저에서 컴파일합니다. 각 jsx는 독립 스코프라 컴포넌트를 `window`에 등록해 공유합니다.

## 🗂️ 문제 데이터 구조 (`questions.js`)

문제는 `window.QUIZ_QUESTIONS` 배열에 들어 있고, 9개 분야(`window.QUIZ_META.cats`)로 분류됩니다.

```
커트 ✂️ · 펌 🌀 · 염색 🎨 · 케어 💆 · 할인규칙 🏷️
멤버십 🎫 · 고객유형 👥 · 점판 🛍️ · 계산 🧮
```

문제 한 개는 3가지 타입 중 하나입니다.

| 타입 | 설명 | 예시 필드 |
|------|------|-----------|
| `short` | **직접 입력**(숫자 키패드) | `a:35000` (정답), `hint` |
| `mc` | **4지선다** | `o:[...]`(보기), `a:1`(정답 인덱스) |
| `calc` | **계산** — 할인%는 객관식, 최종가는 자동 계산 | `base:[{label,price}]`, `o/a`(할인 객관식), `steps:[10,10]`(순차 할인%) |

**문제 추가/수정 예시**
```js
// 단답형
{ id:"cut1", cat:"cut", type:"short", q:"일반 디자이너 <b>커트</b> 가격은?", a:35000 }

// 객관식
{ id:"mem1", cat:"member", type:"mc", q:"멤버십 <b>블루</b> 할인율은?",
  o:["5%","10%","15%","20%"], a:1 }

// 계산 (158,000 → steps 10%,10% 순차 적용 → 127,980원 자동 표시)
{ id:"calc1", cat:"calc", type:"calc", q:"...",
  base:[{label:"남자 일반펌", price:158000}],
  o:["멤버십 10%만","회원권 10%만","멤버십 10% + 회원권 10% 중복","할인 불가"], a:2,
  steps:[10,10] }
```
> `id`는 오답노트가 문제를 추적하는 키이므로 **중복되지 않게** 지어주세요.

## 🎮 기능

- **5가지 모드** — 전체 순서대로 · 랜덤 섞기 · 분야별 · 틀린 문제 재시험 · ⚡타임어택(75초)
- **점수 & 콤보** — 정답 시 점수+XP, 연속 정답 콤보 배율(3·5·10연속), 컨페티/진동 효과
- **레벨 & 직급 뱃지** — 경험치 누적으로 레벨업, 매장 직급으로 등급 표현
  `신입 스타일리스트 → 디자이너 → 수석실장 → 부원장 → 원장 → 대표원장`
- **학습 분석** — 분야별 정답률 막대 + 가장 약한 분야 자동 진단
- **오답 노트** — 틀린 문제 자동 누적(맞히면 제거), 모아서 재시험
- **자동 저장** — `localStorage`에 진행상황 보관(새로고침해도 유지)

## 🧠 핵심 로직 (`util.js` = `window.QU`)

| 함수 | 역할 |
|------|------|
| `gradeShort(input, q)` | 단답 채점(쉼표·'원' 무시, 숫자만 비교) |
| `calcFinal(q)` | 계산문제 최종가(`base`에 `steps` %를 순차 적용 후 합산) |
| `levelInfo(xp)` / `rankFor(level)` | 경험치→레벨 변환, 레벨→직급 뱃지 |
| `buildQueue(mode, profile)` | 모드별 출제 목록 생성(전체/랜덤/분야/오답) |
| `commit(profile, session)` | 한 판 결과를 프로필에 반영 + 저장 |
| `catStats(profile)` | 분야별 정답률 집계 |

**저장 키:** `localStorage["junohair_quiz_v1"]`
**초기화:** 앱 안의 `프로필 → 기록 초기화` 또는
```js
localStorage.removeItem("junohair_quiz_v1")
```

## 📌 데이터 관련 메모

- 원본 `데이터.txt`와 `문제샘플.txt`에서 값이 다른 항목(예: 샴푸 250ml)은
  **공식 가격표인 `데이터.txt` 기준**으로 통일했습니다.
- 가격이 변동되면 `questions.js`의 해당 문제 `a`(또는 `base.price`)만 고치면 됩니다.
